# Гаврилюк Іоанна

## Варіант 1

Програма читає з stdin до 100 рядків тексту (максимальна довжина рядка – 255 символів) до появи EOF. Рядки можуть бути розділені наступними способами:

- CR LF (0x0D 0x0A)

- CR (0x0D)

- LF (0x0A)

Програма здійснює пошук усіх входжень підрядка у кожному рядку. 

**Важливо:**

- Входження не мають перетинатися (наприклад, у рядку "aaa" для підрядка "aa" буде знайдено лише 1 входження).

- Пошук здійснюється у кожному рядку окремо.

- Результати сортуються за кількістю входжень підрядка у кожному рядку. Використовується алгоритм bubble sort. Відсортовані результати виводяться у stdout у форматі:

```
<кількість входжень> <індекс рядка у текстовому файлі починаючи з 0>
```

**Приклад роботи**

Вхідні дані:

```
aaaaa bbaa
aaz a
```
Запуск програми:
```
python prijv1.py aa
```
Результат:
```
1 1
3 0
```
## Функціональність

- Зчитування рядків з stdin до EOF.

- Пошук усіх входжень підрядка у кожному рядку без перетинань.

- Сортування результатів за кількістю входжень за допомогою bubble sort.

- Виведення відсортованих результатів у консоль.
